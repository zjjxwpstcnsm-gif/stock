# 知权 · 证券考试练习

免费的股票 / ETF 期权开户知识练习网站，首版聚焦**上交所个人投资者知识测试**。

- 100 道原创四选一练习题，附答案、逐题解析与参考资料链接。
- 综合模拟卷，以及一级、二级、三级分级模拟卷。
- 按章节配比随机组卷，每份卷内题目不重复。
- 限时作答、题目跳转、标记、交卷确认、到时自动交卷。
- 本地保存答卷，刷新或退出后恢复；考试计时不会暂停。
- 专项练习、自动错题本、最近 50 次结果及逐题复盘。
- 适配手机与桌面，无账号、无后端、无外部运行依赖。

## 考试配置

| 模拟类型 | 题量与分值 | 时长 | 章节配比 | 合格条件 |
| --- | --- | --- | --- | --- |
| 一级 | 20 × 5 分 | 20 分钟 | 基础 12、备兑与保险 8 | ≥70 分 |
| 二级 | 10 × 10 分 | 20 分钟 | 买入开仓 10 | ≥70 分 |
| 三级 | 10 × 10 分 | 20 分钟 | 卖出开仓 10 | ≥70 分 |
| 综合 | 20 × 5 分 | 30 分钟 | 6、4、5、5 | ≥70 分且三部分均 ≥60% |

综合第一部分合并第一、二章，需至少对 6/10；第二、三部分各至少对 3/5。**总分达到 70 分但任何部分未达标，仍判不合格。**

配置依据：[上交所 2026 年修订业务指南](https://www.sse.com.cn/lawandrules/guide/options/c/c_20260609_10821175.shtml)，官方 DOCX 第三章第三节（五）（六），2026-09-29 已直接下载并核验。题型参考公开历史样卷的单项选择题；新指南该条款没有单独重述题型。未将银河官网练习的 80 分线或旧版三级 20 题配置混入。

## 内容边界

这是独立学习项目，不代表交易所、银河证券或其他机构。题目是独立编写的知识练习，不是正式考试原题，不承诺覆盖全部实际题库。通过本网站不等于取得正式知识测试成绩或交易权限。

用户提供的[雪球参考链接](https://www.xueqiu.com/9465897807/256370486)当前未成功读取正文；保留在来源说明中，**没有将未读取内容虚构为已收录题库**。若后续取得原文及适当转载授权，可逐题校核后追加，须标识来源和版本。

首版不含深交所测试、期货开户测试或证券从业资格测试。正式逐级考试有先后顺序，本站为学习开放各级练习。最终预约规则与其他开户条件，以经营机构当次通知为准。

题库 100 道：基础 30、备兑与保险 20、买入 25、卖出 25。所有计算题的金额、假设与正确项在源代码中可审阅。参考链接在 `src/config.js` 中维护；链接是知识依据，不表示题目摘录自该页面。

## 本地运行

需要 Node.js 22+，没有第三方 npm 依赖。

```sh
npm ci
npm test
npm run build
npm run dev
```

打开 http://localhost:4173 。构建结果为 `dist/`。静态路径全部相对引用，支持 GitHub Pages `/stock/` 子路径。

## GitHub Pages

工作流 `.github/workflows/pages.yml` 在推送 `main` 后测试、构建并部署。仓库 **Settings → Pages → Source** 设为 **GitHub Actions**。工作流尝试自动启用 Pages；若 GitHub 的令牌权限不允许首次启用，需仓库管理员在该设置页完成一次配置，然后重跑失败的工作流。

## 结构与验证

- `src/questions.js`：原创题库，首个选项为编写时正确项，导出时确定性轮换选项位置并同步答案索引。
- `src/config.js`：题库版本、章节、考试配置、参考来源。
- `src/engine.js`：随机组卷、判分、恢复校验、截止时间和进度更新。
- `src/app.js`、`src/style.css`：界面、交互及本地保存。
- `tests/engine.test.js`：章节配比、综合卷分项门槛、计时恢复、损坏记录拒绝、错题重练与计算样例。

作答存储键为 `zhiquan.practice.v1`。新版本题库变更应同步更新 `BANK_VERSION`，避免旧答卷对应错误答案。存储不可用时显示提示且允许内存作答；清理浏览器数据会删除本机记录。纯静态应用的答案可从源代码查看，因此仅适用于自主学习，不能作为正式监考系统。
