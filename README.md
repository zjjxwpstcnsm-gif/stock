面向中文金融考试的静态学习应用：**8个科目、95章系统课程、2838道训练题**。从系统教程、互动图解到随机刷题、专项练习和限时模拟，所有学习记录保存在当前浏览器。

## 当前版本：2026-10-13.4

本轮新增64道原创概念辨析，八科各8道，其中32道计算题由独立公式复算并核对展示选项。每题含四项辨析、对应课程、参考条款或模型假设和核对日期。题库从2774题增至2838题；既有题号、来源题、收藏与学习记录保留。

学习空间新增24组「概念对照」：每科3组，分清相似概念后可直接定位情景题或返回完整课程。随机页新增「回看已答题」，展示当前科目最近20条已确认的随机作答，含跨内部批次的历史；只读、不重复计分、不泄露未提交答案。回看区域的数字键不会误答当前题。

**随机刷题无需任何配置。** 在任意科目点击“随机刷题”即进入当前科目全部题库。单选／判断／单答案综合题点选后显示解析；多选须明确提交。解析不自动跳走，读懂后手动下一题。原有“随机X题／范围／模式”设置已移除，不要按旧版截图寻找配置面板。

一轮按题号不重复，题池用尽后重新洗牌；“持续刷题”指重复利用有限题库，不是无限独立新题。逐题保存并支持刷新恢复。专项练习仍可按章节等条件筛选，**不会限制随机刷题的完整题池**。存在未完成模拟卷时，随机刷题不会重置其截止时间。

本轮题设、32道复算和交互边界见 **[概念辨析审校记录](docs/clinic-audit.md)**。此前64道情景研判及38道复算见 [情景研判审校记录](docs/workshop-audit.md)，96道易错精练及44道复算见 [精练审校说明](docs/precision-audit.md)。交互与视觉设计见 [随机刷题说明](docs/random-practice.md)、[设计说明](docs/frontend-design.md)。

## 理论学习与复习

课程按原理、结构、案例、易错点、自测及同章练习组织。期权保留损益、Greeks、备兑保险与组合策略互动模型；基金保留NAV、组合风险和私募现金流图解；其他模块包括债券折现、久期与收益率曲线、卖出套保与基差实验。图解是模型教学，不构成交易建议。

阅读支持章节导航、大字模式、专注阅读、已读记录和打印。搜索覆盖八科课程正文、题干、考点及选项，不在搜索结果泄露答案。专项练习支持章节、来源、年份、题型、关键词、难度、收藏、未练和错题条件，以及空结果保护。

复习工作台优先最近答错，其次未练，最后已练；同层级分散章节，尽量避免标记过的同家族参数题扎堆。显示练习覆盖率和实际累计正确率，**不以一次答对宣称掌握，不预测通过率**。收藏与答卷临时标记分别保存，支持全科导出、导入及合并备份。

基金课程提供2026官方大纲35章对应讲解和15章入门课程。大纲清单包含413条要求（108／153／152），连接课程、练习与原文页。清单完整表示范围索引完整，**不表示教材所有细表、数字、期限及法条例外均已展开，也不表示每条要求都有独立题目**。证券、期货为主题式学习框架，应结合当次大纲、教材和有效规则学习。

## 来源题与准确性边界

54道回忆题来自公开考后整理，10道期权题来自公开历史样卷。每题标记发布方、年份或场次、原始URL、来源页题号和整理说明。使用本站文字重述考查关系、核对主要数值并解释歧义或历史口径，**不是逐字原题、协会认证原卷或完整历年试卷**；无法独立认证真实考场题序，没有编造完整原卷。

来源档案位于各科“真题资料”，代码在 `src/fund-recall-data.js`、`src/verified-questions.js`。法律文本与官方大纲作为原创题的参考依据，不能因此把原创称为官方题。规则提示显示有日期的核对快照，不是实时法规监控；业务办理与正式考试以有效官方文件及当次公告为准。

已有情景精练160题、易错精练96题、情景研判64题，以及本轮概念辨析64题，均有四项解析。未宣称全库经过独立专家审定。发现争议时，可使用随机题下的“反馈此题”：打开GitHub预填草稿，**需自行登录、核对并提交**。链接不携带答案、学习进度或账户信息，请不要在反馈中填写个人交易记录。

## 开发、测试与GitHub Pages

纯HTML、CSS、原生ES Modules，无运行时服务端、登录或付费模型调用。Node.js ≥22。

```sh
npm ci
npm test
npx playwright install --with-deps chromium
npm run test:browser
npm run build
npm run dev
```

`npm test`包括94项单元／内容／构建检查，含本轮32个数值案例的独立复算及边界测试。浏览器回归覆盖桌面与手机，含八科直接刷题、即时反馈、多选、刷新、旧会话、计时考试、备份、新题档案、比较卡、已答回看、跨批次与回看快捷键隔离。

GitHub Pages的Source设为 **GitHub Actions**。推送 `main` 触发 `.github/workflows/pages.yml`：测试→构建→部署→对真实Pages站点做桌面／手机验证。源码、CSS及整个本地模块依赖图统一带内容哈希，`version.json`用于核对发布版本；不能只凭工作流已启动就视为上线成功。

`improve/**` 分支及PR触发质量审查，并保留源码快照和浏览器报告。学习数据在浏览器localStorage中，不随部署上传；建议定期导出备份，清理浏览器数据或更换设备前尤其如此。
