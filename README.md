# 知权 · 金融研习

面向中文金融考试的静态学习应用：**八个科目、95章系统课程、2,454道训练题**。从原理讲解、案例、互动图解，到章节练习、可追溯来源题与限时模拟，使用同一套学习流程。

**在线网站：[zjjxwpstcnsm-gif.github.io/stock](https://zjjxwpstcnsm-gif.github.io/stock/)** · [课程全景](https://zjjxwpstcnsm-gif.github.io/stock/#catalog)

## 理论学习与界面

- 深色侧栏与浅色学习工作区，首页集中显示课程进度、下一章、模拟入口、章节练习、错题与真实本机统计。
- 课程按“问题与原理 → 知识结构 → 案例推导 → 工作场景 → 易错点 → 自测 → 同章练习”组织。新科目强调法律层次、条件、程序与风险辨析。
- 期权课程保留损益、定价、Greeks、备兑保险与组合策略互动模型；基金课程保留NAV、组合风险及私募现金流图解。
- 新增债券折现实验：年付息现金流、价格与收益率曲线、麦考利久期和修正久期；新增卖出套保实验：现货、期货损益与基差对有效售价的影响。当前参数位置同步标在SVG曲线上。
- 阅读支持本章内容跳转、大字模式、专注阅读、章末自测、已读进度、章节翻页与打印。
- 全科搜索课程正文、题干、考点与选项，可按当前科目／全部八科、课程／题目筛选。搜索题目不显示答案，链接可定位到单题练习。
- 专项练习支持章节、来源、来源年份、题型和考点关键词，提供匹配数量、零匹配提示与空卷保护。
- 单选、判断、综合题选择一个选项；多选题逐项选择或取消，选全才得分。答卷恢复、错题本与逐题复盘均支持多选。
- 页面适配桌面、手机和窄屏；提供跳到正文、明确键盘焦点、选项状态、图表说明与减少动画偏好支持。

基金课程继续提供2026官方大纲的35章对应讲解和15章入门课程。大纲清单收录全部413条要求（108／153／152），连接章节、同节练习和PDF原文页。**清单完整表示范围索引完整，不表示所有教材细表、数字、期限及法条例外已逐项展开，也不表示每条要求都有独立题目。**证券和期货课程为主题式学习框架，需要结合当次大纲、教材和有效规则继续学习。

## 真题来源与整理方式

54道回忆题来自2023—2026年公开考后整理；10道期权题来自2015年公开历史样卷。每题标记发布方、年份／场次、来源URL、来源页题号、核对日期及整理说明，可以打开原页对照。

来源题保留考查关系、主要数值，以本站文字重述并独立复核解析。条件不足、表述歧义、历史口径或排版缺项会说明修订之处。**不是逐字原题、协会认证原卷或完整历年试卷**；无法独立认证真实考场题序。未找到可核验的协会公开完整原卷，未编造补齐，也未批量转载第三方题库。

原始出处及逐题档案位于各科“真题资料”页。数据分别维护在 `src/fund-recall-data.js` 与 `src/verified-questions.js`。期权历史样卷的时间、题量、单位及参数不能直接套用当前考试。

## 模拟配置

| 科目／卷型 | 题量 | 时间 | 本站达标条件 | 配置边界 |
| --- | ---: | ---: | --- | --- |
| 期权综合卷 | 20 | 30分钟 | ≥70分且三部分分别≥60% | 上交所2026年业务指南，章节6／4／5／5 |
| 期权一级卷 | 20 | 20分钟 | ≥70分 | 基础12题、备兑保险8题，每题5分 |
| 期权二／三级卷 | 各10 | 20分钟 | ≥70分 | 对应章节，每题10分 |
| 基金三科 | 各100 | 120分钟 | ≥60分 | 每题1分；入门20题＋大纲模块80题为教学配比 |
| 证券两科 | 各120 | 120分钟 | 正确率≥60% | 四种题型；60／30／20／10题为教学配比，换算为100分 |
| 期货两科 | 各130 | 100分钟 | ≥60分 | 单选60×0.5、多选30×1、判断20×0.5、综合20×1.5 |

期权综合卷第一部分合并基础和备兑保险，需至少对6／10；买入、卖出各需3／5。只达到总分不保证分项通过。证券配比不冒充官方命题权重；期货规格依据协会公开考试介绍，正式考务以当次公告为准。

每卷内部不重复随机抽题，卷间可能重复。交卷前不显示解析。倒计时按绝对截止时间计算，刷新、离开页面或切换科目不暂停，到期自动交卷。多选／少选／错选均不得分；期货成绩按题型分值计算。综合题为本站独立情景题，不模拟依赖前题答案的题组。

## 学习记录与备份

网站不使用账号、后端、第三方脚本或远程分析。答卷、错题、最近50次结果及阅读进度存在浏览器localStorage，各科独立保存。

在“学习记录”中导出全部八科JSON备份，再到另一设备导入。导入先验证格式、题号、版本、选项和阅读章节，再显示合并预览：

- 阅读进度合并；历史答卷按ID去重，保留最近50份。
- 同题保留作答次数较多的记录，不把相同备份的次数相加。
- 本机进行中的答卷优先保留；截止时间不会因导入重置。
- 写入失败尝试恢复原数据；文件不会上传服务器。

备份包含学习记录和已选答案，请自行保存。清除浏览器数据会清空本机进度，备份可用于恢复。

## 开发与验证

需要Node.js 22+。生产网站无第三方运行依赖，开发依赖仅有Playwright。

```sh
npm ci
npm test
npx playwright install chromium
npx playwright test
npm run build
npm run dev
```

本地打开 http://localhost:4173 ，构建结果为 `dist/`。资源采用相对路径，支持GitHub Pages `/stock/` 子目录和 `?subject=<id>#course/<lesson>` 等链接。

42个单元／数据用例验证原题不变、全部题目结构与出处、组卷配比、加权达标边界、多选恢复、480个新增参数计算案例、定价／Greeks／现金流模型、大纲413项索引和备份合并。42个桌面／手机浏览器用例覆盖全部95章、选项交互、答案不提前显示、错题移除、倒计时恢复、来源筛选、全科搜索、阅读偏好、备份导入、移动端布局和旧记录兼容。

`tests/browser/`生成截图与报告。GitHub Actions在 `main` 推送后执行全部验证，成功后构建并部署Pages，上传浏览器验证产物。Pages的Source使用GitHub Actions。
