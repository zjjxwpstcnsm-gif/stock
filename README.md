# 知权 · 证券考试练习

免费的股票 / ETF 期权开户知识练习网站，首版聚焦**上交所个人投资者知识测试**。

- 500 道原创四选一练习题，附答案、逐题解析与参考资料链接。
- 综合模拟卷，以及一级、二级、三级分级模拟卷。
- 按章节配比随机组卷，每份卷内题目不重复。
- 限时作答、题目跳转、标记、交卷确认、到时自动交卷。
- 本地保存答卷，刷新或退出后恢复；考试计时不会暂停。
- 专项练习、自动错题本、最近 50 次结果及逐题复盘。
- 适配手机与桌面，无账号、无后端、无外部运行依赖。

## 期权系统教程

从侧栏“系统教程”或首页教程入口进入，也可以直接打开 [教程首页](https://zjjxwpstcnsm-gif.github.io/stock/#course/basics)。

新增 12 章原创教程：权利与义务、合约与术语、四种到期损益、交易与行权、权利金拆解、定价与波动率、Delta/Gamma、Theta/Vega/Rho、备兑与保险、组合策略、保证金与风险、复习与术语速查。每章包含例子、易错点、带解析的小测和官方/专业参考资料，可跳转至对应的题库模块。

- 7 组互动图解：四种基本头寸、时间价值衰减、定价、Delta/Gamma、Theta/Vega/Rho、备兑与保险、价差/跨式/领口；另有权利义务对照图和交易生命周期图。
- 曲线直接由本地数值计算绘制 SVG，调整滑块和下拉框会同步更新曲线与金额；不使用外部图片或图表服务。
- 每章支持 `#course/<id>` 链接、浏览器前进/后退和刷新；独立记录已读章节与上次选择。原有答卷、错题和历史记录沿用原存储键。
- 到期损益明确包含初始权利金，按合约单位换算。定价实验使用无分红欧式 Black–Scholes，Theta 按自然日、Vega/Rho 按一个百分点；不是实时行情、保证成交价格或正式考试原题。
- 沪市 ETF 行权与交收说明依照上交所合约条款和到期提示；一般 Greeks 理论参考 OIC 和深交所投教，不混用海外交易制度。各章来源和核对日期在页面显示。

教程源码：`src/course-data.js`（正文）、`src/course-math.js`（数值模型）、`src/course-charts.js`（互动 SVG）、`src/course.js`（阅读与交互）、`src/course.css`（响应式布局）。`tests/course.test.js` 校验基准定价、平价关系、Greeks 数值差分及组合损益；`tests/browser/course.spec.js` 验证章节导航、图解控制、进度保存、答卷兼容与存储不可用时的阅读。

教程进度键为 `zhiquan.course.v1`，仅保存在当前浏览器；清理本地数据会清除阅读记录。教程自测不计入 500 题练习统计或模拟考试成绩。

## 考试配置

| 模拟类型 | 题量与分值 | 时长 | 章节配比 | 合格条件 |
| --- | --- | --- | --- | --- |
| 一级 | 20 × 5 分 | 20 分钟 | 基础 12、备兑与保险 8 | ≥70 分 |
| 二级 | 10 × 10 分 | 20 分钟 | 买入开仓 10 | ≥70 分 |
| 三级 | 10 × 10 分 | 20 分钟 | 卖出开仓 10 | ≥70 分 |
| 综合 | 20 × 5 分 | 30 分钟 | 6、4、5、5 | ≥70 分且三部分均 ≥60% |

综合第一部分合并第一、二章，需至少对 6/10；第二、三部分各至少对 3/5。**总分达到 70 分但任何部分未达标，仍判不合格。**

配置依据：[上交所 2026 年修订业务指南](https://www.sse.com.cn/lawandrules/guide/options/c/c_20260609_10821175.shtml)，官方 DOCX 第三章第三节（五）（六），2026-09-29 已直接下载并核验。题型参考公开历史样卷的单项选择题；新指南该条款没有单独重述题型。未将银河官网练习的 80 分线或旧版三级 20 题配置混入。

## 内容边界

这是独立学习项目，不代表交易所、银河证券或其他机构。题目是独立编写的知识练习，不是正式考试原题，不承诺覆盖全部实际题库。通过本网站不等于取得正式知识测试成绩或交易权限。

用户提供的[雪球参考链接](https://xueqiu.com/9465897807/256370486)在 2026-09-29 检查时，搜索索引能找到文章标题，但带 `www` 的直接请求返回 HTTP 567「访问提示」，不带 `www` 的请求返回阿里云 WAF 校验脚本，未取得可核验的正文。此证据说明本次访问被校验页面阻挡，不能据此断定文章删除或对所有用户均不可访问。**未收录、复述或冒称核验了该文原题**；可尝试通过普通浏览器或雪球 App 查看，后续取得原文及适当转载授权后再逐题校核。

首版不含深交所测试、期货开户测试或证券从业资格测试。正式逐级考试有先后顺序，本站为学习开放各级练习。最终预约规则与其他开户条件，以经营机构当次通知为准。

题库 **500 道**：基础 **150**、备兑与保险 **100**、买入 **125**、卖出 **125**。本次在原 100 题基础上增加 250 道知识与情景题、150 道计算案例。计算案例覆盖 45 类核算方式，包含盈利、亏损、盈亏平衡、份额错配、调整合约单位、费用、保证金公式分支，以及 Greeks 的方向和单位。

所有题目均附四个选项、唯一答案、解析与参考链接。规则题以上交所规则及 2026 年指南为依据；深交所投教和 OIC 用于通用数学、策略、风险指标知识，**不混用深市或美股考试与交易制度**。Greeks、跨式和价差包含拓展学习内容，不保证属于正式开户测试的每次出题范围。保证金示例给出明确题设公式，不将其冒充所有券商的实时标准。

参考链接在 `src/config.js` 中维护；链接是知识依据，不表示题目摘录自该页面。150 道新增计算案例携带核算输入，由 `tests/calculations.test.js` 独立复算，并检查每题只有一个数值正确选项。

## 本地运行

需要 Node.js 22+。网站运行无第三方依赖；开发依赖仅用于 Playwright 浏览器验证。

```sh
npm ci
npm test
npm run build
npm run dev
```

运行桌面与移动视口的浏览器用例：

```sh
npx playwright install chromium
npx playwright test
```

打开 http://localhost:4173 。构建结果为 `dist/`。静态路径全部相对引用，支持 GitHub Pages `/stock/` 子路径。

## GitHub Pages

工作流 `.github/workflows/pages.yml` 在推送 `main` 后测试、构建并部署。仓库 **Settings → Pages → Source** 设为 **GitHub Actions**。GitHub 的工作流令牌不支持首次启用 Pages，需仓库管理员在该设置页完成一次配置，然后重跑失败的工作流。测试与构建单独运行，构建产物在 Pages 未启用时也会上传。

## 结构与验证

- `src/questions.js`：保留原 100 题并合并扩展题；每章追加后确定性轮换选项，保持原题 ID 与答案不变。
- `src/questions-extra.js`：250 道新增知识与情景题。
- `src/questions-calculations.js`：150 道新增计算案例及核算输入。
- `tests/calculations.test.js`：独立核算全部新增计算题，覆盖 45 类公式、唯一正确项及到期损益边界。
- `src/config.js`：题库版本、章节、考试配置、参考来源。
- `src/engine.js`：随机组卷、判分、恢复校验、截止时间和进度更新。
- `src/app.js`、`src/style.css`：界面、交互及本地保存。
- `tests/engine.test.js`：章节配比、综合卷分项门槛、计时恢复、损坏记录拒绝、错题重练与计算样例。
- `tests/browser/flow.spec.js`：桌面 / 手机完整作答、刷新恢复、提前交卷、错题重练、到时交卷、存储损坏及页面宽度检查。CI 保留 HTML 报告与截图。

作答存储键为 `zhiquan.practice.v1`。本次题库版本为 `2026-09-29.2`；仅追加题目，使用摘要测试锁定原有 100 题，兼容 `2026-09-29.1` 的未完成答卷、历史与错题记录。以后若修改已有题目或答案，须更新 `BANK_VERSION` 并移除受影响的 `COMPATIBLE_BANK_VERSIONS`，避免旧答卷被错误判分。存储不可用时显示提示且允许内存作答；清理浏览器数据会删除本机记录。纯静态应用的答案可从源代码查看，因此仅适用于自主学习，不能作为正式监考系统。
