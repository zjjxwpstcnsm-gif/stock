# 随机刷题：直接开始

当前版本：2026-10-13 学习书桌升级。

首页“开始随机刷题”或导航“随机刷题”直接打开当前科目的一道题。也可打开 `/?subject=fund1#drill` 等科目链接。没有范围、题数、模式或即时解析开关。

单选、判断点选后显示答案及解析；多选可以取消勾选，点击“提交多选答案”后显示解析。读完后点击“下一题”，不会自动跳过解析。键盘数字 1–4 选择，反馈区域聚焦后 Enter 进入下一题。

始终使用当前科目完整题库。专项练习的筛选不会带入随机刷题。每轮随机顺序，不重复抽取；整轮完成后重新洗牌，避免新一轮首题与上一轮末题连续重复（题池超过一题时）。无限续刷指循环题库，并非生成无限新题。

内部按小批保存记录，批次结束不出现结算或配置页，只需继续“下一题”。手动结束仅统计已确认答案；一道也未答时回到学习空间。

刷新或重新进入自动恢复当前题、选择与已揭示解析。切换科目保持刷题模式，各科记录隔离。旧版有限/筛选刷题记录恢复时保留答案，自动扩展为本科全部题目并开启即时反馈、连续刷题。

若有未完成模拟卷，进入随机刷题会暂存它，不覆盖答卷，也不会暂停考试计时。首页“继续作答”可恢复原模拟卷，随机刷题也保留。暂存答卷随学习记录一并导出、校验与合并。
