# 随机刷题 · 2026-10-13.2

## 使用方式

进入任一科目左侧「随机刷题」，或首页「去随机刷题」。选择全部章节或单章，并可叠加来源、年份、题型、关键词、未练/错题/收藏、难度、内容批次筛选。设置随机 X 题或无限续刷，输入 1–200 题，亦可使用 5 / 10 / 20 / 50 快捷值。

默认单选、判断以及单答案情景题点选后立即判分、显示解释；多选题可反复勾选，提交后才揭晓。不自动跳过解析。关闭「点选后立即显示答案」则先选后确认。旧专项练习和考试保持原有确认/交卷规则。

## 抽题与续刷契约

- 以本次筛选后题池建立 Fisher–Yates 洗牌队列；一轮内每个题目 ID 最多出现一次。已有题库仍可能包含明确标注的参数变式，ID 不重复不等于考点完全不同。
- 一轮用尽后重新洗牌；多于一道题时，新轮首题不与上轮末题相同。单题题池不可避免地重复同一题。
- 按组消费队列，到轮末不足 X 题时使用剩余题数，不在同组中补入重复 ID。有限模式结算后可「再随机一组」；无限模式答完一组后点击「下一组·继续刷题」，持续循环。
- “无限”指不限累计作答次数，不宣称无限独立新题，不调用生成式模型现场出题，不将原创题标成真题。
- 开始后冻结题池；错题或未练状态的变化不会在中途改动范围。需要改变范围时重新开始。

## 记录与安全性

每题确认只记一次进度，多次点击或重按不会增加同次尝试。答后立即保存；刷新后可用「继续作答」恢复当前题、答案、解析状态、累计统计和待抽队列。各科独立保存。

每组结算为一条学习历史，最多保留最近 50 组；逐题累计进度仍保留。仅最近一条历史保留可继续抽题的题池元数据，较旧组保留作答与解析但不重复存储整份题池。中途结束只计已确认题，未答题放回本次待抽队列。退出页面不是删除，重新开新会话会提示替换。

新会话增加可选 `drill` 字段；旧会话无需该字段。恢复、导入均验证题池 ID、去重、计数范围、剩余队列和当前组不相交等约束。沿用既有备份格式与旧版本兼容表。浏览器禁用存储或额度不足时显示警告，不能保证关闭后的恢复。

## 可访问性与测试

题目对错同时显示文本，不仅靠颜色。答案反馈有状态区域并接收焦点。多选使用 checkbox 语义；单选使用 radio 语义。即时模式方向键只移动焦点，Enter/空格才提交；数字键可直接作答，按键重复事件忽略。手机布局把启动设置置前，支持安全区和减少动态效果偏好。

`tests/drill.test.js` 覆盖随机去重、轮末短组、跨轮相邻避重、单题池、2000组连续抽题、累计统计、恢复与导入、损坏状态拒绝等。
`tests/browser/drill.spec.js` 覆盖八科答后解析、单击启动、多选提交、有限与无限模式、错误答案、刷新、键盘和两种视口。
