# 计算训练分步复核 · 2026-10-14

本次改进的是已有480道参数变式，不增加题量，也不把480题描述为480个独立知识点。32类模型分布在六个科目，其中跨科共用家族重复出现。题号、四个选项及答案位置完全保留，以避免改变已有作答记录的含义。

## 修正了什么

- 原先部分基差、期货盈亏、折现题把《期货和衍生品法》列为直接计算依据。法律文本不证明这些公式；现改为本编辑复算清单，并保留原课程来源键，仅用于背景追溯
- 每题在原解析后增加带入本题数字的分步复算，明确方向、单位转换、分母及最后结果
- 本批按题设假定进行教学计算，题设费率、保证金率、合约单位不代表统一现行业务规则
- 独立复算测试仍使用与生产代码分离的32个数值函数；另检查全部480题的展示结果和新解析。没有给数值干扰项虚构未经证实的错误思维过程

## 模型与假设

| 家族 | 关系 | 边界 |
| --- | --- | --- |
| delta-position / gamma-adjust | ΔV≈Delta×ΔS×单位×张数；新Delta≈原Delta＋Gamma×ΔS | 局部线性近似，敏感度按题设固定 |
| vega-position / theta-position / rho-position | 敏感度×相应输入变化×张数 | 波动率及利率用题设“百分点”，Theta按日 |
| put-insurance / covered-upside / credit-spread | 保护性认沽价值下限／最大损失上限、备兑收益上限、信用价差宽度减净收入 | 同标的、单位匹配、同到期，忽略费税 |
| net-assets / expense-impact | 净资产＝资产−负债；净值＝净资产/份额 | 统一万元与万份口径 |
| fee-rate | 计费基数×年费率/365 | 365天仅为题设，不推广为统一产品规则 |
| subscription-units / redemption-net | 外扣净申购额＝总额/(1＋费率)；赎回净额＝份额×净值×(1−费率) | 无其他费用和中间舍入 |
| cash-distribution / reinvest-shares / holding-return | 份额×每份分红；分红现金/再投净值；(价差＋现金分红)/初始净值 | 现金分红不凭空增加财富；持有期收益题不再投资 |
| postmoney / stake / enterprise-bridge | 投前＋新增权益；新投资额/投后；企业价值＋现金−有息债务 | 无其他稀释或价值调整，仅新增股权融资 |
| dpi / rvpi / tvpi | 分配/实缴；剩余价值/实缴；二者之和 | 分子分母同口径，不是年化回报率 |
| cash-waterfall / cash-call | 题设返本后利润×carry比例；认缴−实缴 | 不含门槛、追赶、税费等未给定条款 |
| discount / duration | 一年后现金/(1＋年利率)；ΔP/P≈−修正久期×Δy | 久期忽略凸性；百分点先转小数 |
| nominal-value / margin / pnl | 价格×单位×手数；名义值×题设保证金率；多头价差×单位×手数 | 保证金不是损失上限 |
| basis / index-fair / call-profit | 现货−期货；S[1＋(r−q)T]；max(S−K,0)−权利金 | 基差符号按定义；简单持有成本；认购到期损益 |

测试：`tests/academy.test.js`独立计算480题；`tests/content-integrity.test.js`校验解释完整性及前一版所有2838道题的ID、选项和答案序列散列。该散列是学习记录兼容性防线，不是正确性认证。新增题与法规纠错另见对应审校报告。
