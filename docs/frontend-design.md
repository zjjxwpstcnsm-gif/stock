# 知权：学习书桌设计 / 2026-10-13

依据用户指定的 https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md。

## Brief
证券考试学习工具；核心任务是读懂原理、判断选项并复习。随机刷题无需设置，当前科目直接开始，即时解析，无限继续。专项练习保留筛选。

## 第一轮方案与自审
最初的绿色 KPI 仪表盘和重复卡片不适合持续阅读，且与现有界面区别不足。改为冷色学习书桌：只把视觉重点放在首页的蓝色练习书签区，其余界面留白、左对齐。去掉渐变、英语装饰标签和重复营销横幅；真实题量保留但不做主视觉。

颜色：云白 #F5F7FB；纸白 #FFFFFF；墨蓝 #223550；书签蓝 #315BC4；雾蓝 #E7EDF7；石板灰 #65768C。正确 #236B55；错误 #A3483F，结合文字与符号，不依赖颜色。
字体：中文标题用 Songti SC / Noto Serif CJK SC；正文用 PingFang SC / Noto Sans CJK SC。系统本地字体，无外部字体请求。

```
科目导航 | 当前科目 / 页面标题
         | 随机刷题（直接开始） | 下一章阅读
         | 本机学习概览（真实数据）
         | 章节列表           | 复习与来源
         | 模拟考试
```

答题是一张宽度受控的阅读页面：当前科目、累计统计、题干、选项、即时解析、下一题。不展示题数、范围、模式或解析开关；不展示内部批次。保留题目出处、收藏、本机保存与手动结束。单选/判断即答，多选选择完再确认。没有自动跳题。

## 交互与可访问性
至少 44px 主要点击区；可见键盘焦点；1–4 选择，答案揭晓后 Enter 下一题；动效仅用于用户触发的状态变化；遵循 reduced-motion。窄屏导航横向滚动，刷题底部操作区保留安全区，正文不横向溢出。切换科目后直接进入该科刷题；刷新恢复当前题和已揭晓答案。开始刷题不得丢弃未完成的模拟，原答卷暂存并可继续。

## 2026-10-17：首页的后续学习路径

本轮重新读取用户指定的 frontend-design 技能原文，沿用上述六色、中文宋体标题与系统无衬线正文。蓝色随机练习区继续承担唯一视觉重点；其余区域用实际阅读状态、作答次数和清楚的动作名称帮助用户接着学。

- 教程卡区分首次阅读、继续上次未读章节、补读未完成章节和全部读完后回看；全部已读时保留最近章节，不回退首章造成进度重置的错觉。
- 复习区直接开始现有的 10 题复习流程，说明实际错题或未练题数量，并保留完整复习工作台入口。按钮复用现有答卷保护流程；随机刷题仍然直接进入，暂存的随机答卷也明确标为“继续”。
- 概览区分去重题量、累计作答正确率和最多 50 份的最近记录；章节显示待纠正数量。在 600px 以下用两列呈现四项概览，提高文字大小；复习与来源分行，保持 44px 以上点击区和可见键盘焦点。

方案自审：不增加另一张推荐卡或连续打卡指标，不为已练题量赋予掌握度含义；把建议放回已有阅读卡与复习区，延续原有的学习书桌布局。回归验证覆盖八科全部已读、跳读后补读、暂存随机答卷，以及反复答题时覆盖与正确率的不同口径。
